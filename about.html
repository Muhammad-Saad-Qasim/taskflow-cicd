About TaskFlow

A lightweight task-management web application.

What is TaskFlow?

TaskFlow is a simple, lightweight task-management application built as part of the DevOps Fundamentals CI/CD assignment. It helps you keep track of your tasks, their priorities, due dates, and completion status — all from a clean, consistent interface.

The application is containerized with Docker and deployed automatically to Render through a GitHub Actions CI/CD pipeline.

Purpose

The goal of TaskFlow is to demonstrate a complete, automated software-delivery workflow: from building individual feature pages, to running continuous integration on every pull request, to continuously deploying the merged result to a live environment.

How to Use TaskFlow

  1. Open the Dashboard to see a summary of your total, pending, and completed tasks.
  2. Go to Add Task to create a new task with a title, description, due date, and priority.
  3. Visit the Task List to view all tasks and filter them by All, Pending, or Completed.
  4. Click any task to open its Task Detail page, where you can mark it complete or delete it.
  5. Use the navigation bar at the top to move between pages at any time.
